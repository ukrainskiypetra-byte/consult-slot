
# Статут проєкту (Project Charter)

## 1. Назва проєкту
**ConsultSlot** — клієнтський вебзастосунок для швидкого запису студентів на консультації до викладачів.

## 2. Мета проєкту
Оптимізувати та автоматизувати процес узгодження часу консультацій для студентів академічних груп. Усунути інформаційний хаос у месенджерах, запобігти подвійним бронюванням та забезпечити прозору візуалізацію вільних 30-хвилинних слотів у позаурочний час (перерви та після пар).

## 3. Цільова аудиторія
* **Студенти (потік 4ІПЗ-23; 3ІПЗс-24 та ін.):** авторизація за ПІБ та групою, перегляд вільних слотів, бронювання в один клік, керування власними записами.
* **Викладачі / Куратори:** зручне додавання вільних слотів через швидкі чіпи часу, модерація розкладу, перегляд загального журналу записів.

## 4. Обмеження та межі MVP (Minimum Viable Product)
* Реалізація за патерном Single-Page Application (SPA) в одному файлі `consult.html`.
* Управління станом та сесіями відбувається на стороні клієнта за допомогою `localStorage` (без розгортання окремого бекенд-сервера).
* Класичний світлий академічний інтерфейс із динамічним лічильником вільних місць.
