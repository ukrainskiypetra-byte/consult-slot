## 📂 Структура репозиторію
* **`assets/`** — графічні матеріали, іконки та скріншоти інтерфейсу.
* **`docs/`** — проєктна документація (`charter.md`, `team-agreement.md`).
* **`packaging/`** — конфігураційні файли збірки та деплою (`config.json`).
* **`scripts/`** — службові скрипти обслуговування кешу (`clean-cache.js`).
* **`src/`** — вихідний код вебресурсу (`consult.html`).
* **`tests/`** — тестові модулі для перевірки логіки (`app.test.js`).

## 🛠 Технологічний стек
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+).
* **Менеджмент стану:** Клієнтське сховище `LocalStorage`.
* **Контроль версій:** Git / GitHub.

## 🚀 Швидкий старт
1. Клонуйте репозиторій на локальний пристрій.
2. Перейдіть у папку `src/`.
3. Відкрийте файл `consult.html` у будь-якому сучасному браузері.
