# 🎨 ConsultSlot Assets

У цій директорії зберігаються візуальні та графічні ресурси для вебзастосунку **ConsultSlot**:
* **Скріншоти інтерфейсу** — демонстрація робочих екранів (вхід, сітка слотів, панель викладача).
* **Іконки та банери** — графічні елементи брендингу та оформлення документації.
* **Архітектурні схеми** — діаграми взаємодії клієнтської частини з `LocalStorage`.
